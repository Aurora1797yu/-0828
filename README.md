# 荔园文化月历 · 深圳大学


## 设计语言
- **中性灰度 + 留白**：米白底（`#FBFBF8`）+ 近黑正文，弱化色彩干扰，把注意力还给内容
- **主色克制**：以"雾蓝 `#6FA8C9`"为主色，"荔园暖金 `#D99A3F`"仅作点缀，整体小清新、扁平通透
- **扁平卡片 + 轻阴影**：去冗余装饰，模块清晰分区，阅读舒适

## 功能模块
| 页面 | 说明 |
|---|---|
| 月历 | 按月视图集中展示全校文化活动，左右切换月份 + 分类筛选（品牌/学术/文艺/体育/劳动），一键报名 |
| 发现 | "荔园必做 N 件事"品牌导览（含"加入一个社团"入口，直达社团页） |
| 社团（新增） | 18 个真实深大社团推荐，按文艺/体育/学术/公益/兴趣分类筛选，可关注 |
| 我的 | 汇总个人已报名活动，空态引导 |

## 深大真实内容
- 活动：荔枝文化节（免费派荔 16 万斤）、"大荔出骐骥"元宵市集、国际文化节、开学/毕业典礼、荔园戏剧节、新年音乐会、社团嘉年华、健康荔园跑、荔枝林劳动养护、荔园青春嘉年华、荔园人文月等 15 项
- 社团：深大戏剧社、荔声合唱团、混合胶囊原创音乐社、DEGREE 舞团、深大摄影协会、深大跑团、羽毛球/极限飞盘/击剑协会、荔园日协、天文爱好者协会、荔进社、志愿者联合会、子归汉服社、银河村科幻协会、观鸟学会、ALFA 动漫协会等 18 个
- 覆盖粤海 + 丽湖双校区

## 使用方式
浏览器直接打开 `index.html` 即可体验（无需后端）。活动/社团数据集中在 `app.js` 的 `EVENTS` / `CLUBS` 数组，对接学校文化活动 API 即可上线，亦可封装为微信小程序页面。

## 技术
纯前端单页 H5，零依赖（HTML + CSS + JS 三个文件）。
